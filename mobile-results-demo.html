Банк результатов: выбор на мобильном

Главная сложность банка — последовательный выбор: подход → область влияния → формулировка результата. Ниже пять рабочих вариантов этого выбора, собранных под телефон. Текущая страница и её дизайн не изменялись.

Текущая страница →
Что не так с текущим мобильным вариантом. Три колонки схлопываются в три отдельные прокрутки высотой 160–200 px: после выбора подхода следующий блок нужно искать на странице, часть списка скрыта во внутреннем скролле, а выбранное состояние теряется из виду. В каждом варианте ниже последовательный выбор решён по-своему — сравните на телефоне.

Вариант 1. Мастер: один экран — один шаг

Три шага с прогресс-баром. Шаг 1 — подход, шаг 2 — область влияния выбранного подхода, шаг 3 — формулировки. Вернуться и поменять любой шаг можно нажатием на прогресс-бар. На длинных списках (например, 17 ценностей) появляется поиск.

  • Всегда видно, где вы находитесь и что уже выбрано.
  • Крупные зоны нажатия, нет вложенных скроллов и скрытых списков.
  • Поиск по областям и по формулировкам внутри шага.
  • Три перехода до результата — чуть больше тапов.
  • Нет одновременного обзора всего дерева.

Вариант 2. Аккордеон: дерево на одном экране

Подходы — секции. Раскрыли подход — появились области влияния, раскрыли область — внутри развернулись формулировки. Открыта только одна ветка; сверху закреплена строка с текущим путём и быстрым сбросом. Есть сквозной поиск по всему банку.

  • Контекст не теряется: всегда видно, где вы в структуре.
  • Нет переключения экранов — один непрерывный список.
  • Сквозной поиск сразу по 155 формулировкам.
  • Длинные ветки дают длинную страницу.
  • Нужен аккуратный сброс «гармошки», чтобы не запутаться.

Вариант 3. Шторка: выбор внизу, результаты сразу

Список формулировок всегда на экране и прокручивается внутри «экрана телефона». Внизу — три кнопки шагов: подход, область, результат. Выбор открывается шторкой снизу; после выбора шторка закрывается, и список мгновенно перестраивается.

  • Результат виден сразу, сравнение формулировок не сбивается.
  • Привычный мобильный паттерн: нижняя панель + шторка.
  • Можно смотреть всё и постепенно сужать выбор.
  • Активный выбор спрятан в шторке — меньше обзора уровней.
  • Шторка и превью результата наслаиваются друг на друга.

Вариант 4. Поиск и фильтры: без обязательных шагов

Сверху — поиск по формулировкам, показателям и ценностям. Ниже — необязательные фильтры: подход → область влияния → ценность. Можно сразу написать запрос, а можно идти последовательно, как в остальных вариантах.

  • Не заставляет проходить три шага: опытный пользователь попадает в цель быстрее.
  • Классическая связка «поиск + фильтры», понятная без обучения.
  • Фильтр по ценностям даёт ещё один вход в банк.
  • Иерархия «подход → область» уходит на второй план.
  • Новичку без запроса сложнее понять, с чего начать.

Вариант 5. Как сейчас, но с выпадающими списками

Минимальное отступление от текущей вёрстки: те же три блока с заголовками «Подход», «Область влияния», «Результаты». Выбор — в нативных выпадающих списках, результаты остаются списком и дополнительно доступны из третьего списка. На телефоне открывается привычный системный пикер.

  • Сохраняет утверждённую структуру страницы почти без изменений.
  • Нативный мобильный пикер вместо трёх вложенных скроллов.
  • Список формулировок не теряется — остаётся на странице.
  • Длинные названия в селекте обрезаются на узком экране.
  • Три блока всё ещё требуют прокрутки страницы вниз.
